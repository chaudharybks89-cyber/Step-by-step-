# Step & Style Android App

This is an Android WebView app project for the Step & Style shoe shop website.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select **app** and run on an Android phone/emulator, or use **Build > Build APK(s)**.

The website is bundled inside the app, including the 20 shoe images and WhatsApp order buttons.
